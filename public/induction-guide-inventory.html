INVENTORY

Overview

Pro Regal Pavilion's Inventory module helps you track and manage stock levels across two sections:

  • FOH (Front of House) — Glassware, Cutlery, Linen, Consumables, Equipment, Cleaning, General
  • Bar — Spirits, Wine, Beer, Mixers, Garnishes, Bar Equipment, Glassware, General

Each section uses separate data storage for clean isolation, with the same workflow and interface.

Key Concepts

Par Level (Minimum Count)

Each item has a Par Level — the minimum stock count you want to maintain. When the current count falls strictly below the par level, the item shows a "Low Stock" alert. An item at exactly the par level is considered "OK".

Adding Inventory Items

(Admin / Super Admin only)

Navigate to Inventory in the sidebar

Select the tab — FOH or Bar

Click "Add Item"

Enter the item Name (e.g., "Wine Glasses")

Select a Category (e.g., Glassware, Spirits)

Set the Unit (e.g., pcs, bottles, boxes)

Enter the Current Count and Par Level

Click "Add Item" to save

Tip: Set the Par Level to the minimum stock you want on hand. The system will flag items that drop below this level.

Performing a Stocktake

(Admin, Super Admin, or Roster Admin)

The stocktake is the primary way to update stock levels. It should be done regularly (e.g., weekly).

Click the "Stocktake" button at the top of the inventory section

A dialog opens showing all items with their current recorded count

Count each item physically and update the number in the field

Click "Save Stocktake"

A Stocktake Report is generated showing previous vs. new counts with differences

Auto-Fulfillment

When a stocktake confirms that a previously low-stock item has reached or exceeded its par level, any "Ordered" order requests for that item are automatically marked as "Received". This streamlines the receiving process.

Example: If "Wine Glasses" had an order marked as "Ordered" and the stocktake shows the count is now at or above the par level, that order is automatically completed.

Order Requests

When items fall below par level, you can submit order requests to replenish stock.

Submitting an Order Request

(Admin, Super Admin, or Roster Admin)

Click "Order Request" at the top of the inventory section

Select the item from the dropdown (low-stock items are marked with ⚠️)

Enter the quantity to order

Add optional notes (e.g., supplier, urgency)

Click "Submit Request"

Quick Tip: The "Order Low Stock" button on the low-stock alert card pre-fills an order request for the first low-stock item with the quantity needed to reach par level.

Best Practices

  • Weekly Stocktakes — Perform stocktakes at the same time each week for consistency
  • Set Realistic Par Levels — Base par levels on average weekly usage plus a small buffer
  • Use Notes — Add supplier info or special instructions to order requests
  • Review Orders Promptly — Approve or reject pending orders quickly to maintain stock flow
  • Export for Records — Export stocktake reports as CSV for auditing and compliance
  • Separate FOH & Bar — Use the correct tab to avoid mixing stock between sections

Frequently Asked Questions

Q: What's the difference between FOH and Bar inventory?

They are completely separate systems with different categories and storage. FOH covers front-of-house items (glassware, linen, etc.) while Bar covers beverage and bar-specific stock.

Q: How does auto-fulfillment work?

When you perform a stocktake and an item's count reaches or exceeds its par level, any orders for that item with status "Ordered" are automatically marked as "Received".

Q: Can Roster Admins approve orders?

No. Roster Admins can view inventory, perform stocktakes, and submit order requests. Only Admins and Super Admins can approve, reject, or mark orders as ordered.

Q: What happens if I set the par level to 0?

The item will never show as "Low Stock" since any count ≥ 0 meets the par level. Only set par level to 0 for items you don't want to track stock levels for.

Q: Can I delete an item that has active orders?

Yes, but the related orders will show "Unknown" as the item name. It's recommended to complete or reject all orders before deleting an item.
