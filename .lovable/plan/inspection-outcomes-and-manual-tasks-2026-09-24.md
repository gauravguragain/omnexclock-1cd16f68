# Inspection outcomes and manual tasks

## Inspections
- Add actions to mark an inspection as Complete, Rescheduled, or No show — needs follow-up.
- For Rescheduled, collect a new date, start time, and end time, then update the existing inspection.
- Refresh Sales & Marketing data after saving so the rescheduled inspection immediately moves to its new date in the Calendar.
- Marking Complete advances an inspection-booked lead to Inspected; No show keeps the lead available for follow-up.

## Tasks
- Add an “Add task” action on the Tasks tab.
- Allow a title, optional linked lead, optional notes, due date/time, and priority.
- Save it as an open manual task so it appears in Tasks and Calendar automatically.

## Verification
- Validate all three inspection actions, rescheduled Calendar data, manual task creation, and successful compilation.
