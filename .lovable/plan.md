# Pro Regal Pavilion rebrand

## Outcome
Replace user-visible Omnex branding throughout the app with Pro Regal Pavilion branding, while preserving all routes, data, permissions, and operational features.

## Changes
- Download and store the official Pro Regal Pavilion logo from the supplied website, then use it for the app, browser icon, installed-app icons, sign-in screens, portals, admin areas, and induction guides.
- Update visible product names, page titles, descriptions, footer text, reports, and email presentation from Omnex/OmnexClock to Pro Regal Pavilion.
- Apply the website’s visual identity: near-black surfaces, warm bronze accent, white text, and Barlow typography through the shared theme tokens.
- Retain each business’s saved theme and logo where the app intentionally supports business-specific branding; use Pro Regal Pavilion as the platform default and fallback.
- Update PWA display names and metadata while keeping existing internal storage keys, route names, database identifiers, and deployment URLs unchanged to avoid regressions.
- Review all remaining Omnex references and keep only non-visible technical identifiers whose renaming could disrupt saved sessions or installations.

## Validation
- Confirm no user-visible Omnex branding remains in the app or guides.
- Verify the app builds successfully.
- Check the main entry screen and key admin/employee views on desktop and mobile for logo, colour, typography, and text visibility.
